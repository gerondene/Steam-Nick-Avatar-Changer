# Steam Nick & Avatar Changer

Смена ника и аватара в Steam из отдельного окна или из командной строки — без
запуска клиента и без ввода пароля. Работает через веб-сессию по одной cookie.

❗Обязательно посмотрите раздел настройки что бы правильно настроить приложение. Долго заходит!❗

## Что умеет

- Смена ника: список пресетов в один клик, перебор по кругу, произвольный ник
- Смена аватара: миниатюры картинок из папки `avatars`, клик — и аватар стоит
- Автосжатие картинок под лимит Steam в 1 МБ, если файл больше
- Семь тем оформления, выбор сохраняется между запусками
- Горячие клавиши на пресеты — можно менять ник прямо из игры
- Полноценный CLI и текстовое меню, если окно не нужно

## 📂Установка

**Готовый exe.** Скачай `SteamNick.exe` из
[релизов](../../releases/latest), положи в любую свою папку и запусти. Python и
библиотеки внутри, ставить ничего не нужно. Windows покажет предупреждение
SmartScreen — сборка не подписана сертификатом, это ожидаемо для бинарников
такого рода.

**Из исходников.** Нужен Python 3.10 или новее:

```bash
git clone https://github.com/gerondene/Steam-Nick-Avatar-Changer
cd Steam-Nick-Avatar-Changer
pip install requests customtkinter==5.2.2 pillow
python steam_nick_gui.py
```

`pillow` не обязателен — без него не будет миниатюр и автосжатия, всё остальное
работает.

## ❗Настройка

Официального API для смены ника у Steam нет, поэтому программа действует как
браузер: берёт cookie твоей сессии и отправляет ровно те же запросы, что и сайт
при нажатии «Сохранить». Нужна одна cookie — `steamLoginSecure`.

1. Открой [steamcommunity.com](https://steamcommunity.com) в браузере и войди в
   аккаунт.
2. Нажми `F12` — откроются инструменты разработчика.
3. Перейди на вкладку **Application** (в Firefox — **Storage**).
4. В левом дереве: **Cookies → https://steamcommunity.com**.
5. Найди в списке строку `steamLoginSecure` и скопируй её **значение** целиком.
   Оно длинное, 300+ символов, и начинается с твоего SteamID64 —
   `76561198...%7C%7CeyJ0eXAi...`. Скопировать нужно всё, включая часть после
   `%7C%7C`.
6. Запусти программу, открой вкладку **Токен**, вставь значение в поле и нажми
   **Сохранить и переподключиться**.

Если всё верно, в заголовке появится твой текущий ник и аватар, а внизу —
`Подключено к 76561198…`. Токен сохранится, второй раз вставлять не придётся.

Если `Ctrl+V` в поле не срабатывает, нажми кнопку **Вставить** рядом с ним —
она берёт значение из буфера обмена напрямую.

Cookie живёт до выхода из аккаунта в браузере. Когда она истечёт, программа
скажет `cookie истёк, скопируй заново` — повтори шаги выше.

## Где лежат настройки

Не рядом с программой, а в стандартной папке Windows:

```
%APPDATA%\SteamNick\
├── config.json            токен, пресеты, выбранная тема
├── state.json             позиция перебора по кругу
├── profile-backup.json    копия профиля до первой смены ника
└── avatars\               твои картинки для аватара
```

Полный путь — `C:\Users\<имя>\AppData\Roaming\SteamNick`. Так exe можно держать
хоть в «Загрузках» и спокойно переносить: настройки, пресеты и картинки
останутся на месте. Открыть папку можно из программы — кнопка внизу вкладки
**Токен**.

Если раньше файлы лежали рядом с программой, при первом запуске новой версии
они переедут сами — ничего копировать руками не нужно.

## Пресеты ников

Часто используемые ники держатся в списке на вкладке **Ник**: клик по строке
ставит ник, `✕` убирает её из списка. Чтобы добавить новый — впиши его в поле
«Свой ник» и нажми **В пресеты**. Кнопка **Следующий по кругу** перебирает
список по очереди, запоминая позицию между запусками.

Список хранится в `%APPDATA%\SteamNick\config.json`, править файл руками не
обязательно:

```json
{
  "steam_login_secure": "76561198...",
  "theme": "Standard",
  "presets": ["первый ник", "второй ник"]
}
```

## Аватары

Картинки лежат в `%APPDATA%\SteamNick\avatars` — папка создаётся сама, и проще
всего открыть её кнопкой **Папка** прямо из программы. Всё, что туда положишь,
появится миниатюрами на вкладке **Аватар**, клик по любой ставит её аватаром.
`⟳` пересканирует после добавления файлов, **Выбрать файл…** берёт картинку из
любого места на диске.

Требования Steam: `jpg`, `png` или `gif` не больше 1 МБ. Файлы крупнее
программа сама пережимает в JPEG, подбирая размер и качество, — гифки не
трогает, чтобы не сломать анимацию, их нужно уложить в лимит заранее.

## Темы

Переключатель в правом нижнем углу. Тема меняет не только цвета, но и радиус
скругления, рамки и шрифт:

| тема | описание |
|---|---|
| `Standard` | тёмный сине-серый, голубой акцент |
| `Legacy` | светло-серый, почти прямые углы — вид старых окон Windows |
| `Steam` | палитра клиента Steam |
| `Midnight` | чистый чёрный, фиолетовый акцент, сильное скругление |
| `Light` | светлая с белыми карточками |
| `Terminal` | чёрный фон, зелёный текст, Consolas |
| `Fatality` | тёмно-серый с коралловым акцентом |

## Командная строка

Для тех, кому окно не нужно. Файл `nick.cmd` — обёртка над скриптом:

```
nick "Новый ник"        поставить конкретный ник
nick -p 2               ник из presets[2]
nick -c                 следующий по кругу
nick -l                 показать текущий ник и список пресетов
nick -a кот.png         поставить аватар из файла
nick                    текстовое меню
```

Двойной клик по `nick.cmd` открывает интерактивное меню — там же пункт `[a]` со
списком картинок из папки `avatars`.

## Горячие клавиши

`nick.ahk` требует [AutoHotkey v2](https://www.autohotkey.com/). Запусти файл —
в трее появится иконка, и заработают сочетания:

| клавиши | действие |
|---|---|
| `Ctrl+Alt+1…4` | пресет по порядку в списке: `1` — первый, `4` — четвёртый |
| `Ctrl+Alt+0` | следующий по кругу |

Работает поверх игры: ник меняется на живой сессии, перезапускать ничего не
нужно.

## Как это работает

Ник ставится через `POST /profiles/<id>/edit/` с `type=profileSave` — той же
формой, что и страница редактирования профиля. Программа сначала читает
существующие поля (био, локацию, ссылки) и отправляет их без изменений вместе с
новым ником, иначе Steam обнулил бы их. Перед первой сменой исходный профиль
сохраняется в `profile-backup.json`.

Аватар грузится через `POST /actions/FileUploader` с `type=player_avatar_image`
и файлом в multipart.

Пароль, Steam Guard и клиент Steam не задействованы, в память игр или процессов
программа не лезет.

## Ограничения

- Ник — от 2 до 32 символов, это лимит Steam
- Аватар — до 1 МБ, форматы `jpg`, `png`, `gif`
- Steam ограничивает частоту смены ника, «раз в секунду» не выйдет
- История имён видна в профиле публично, скрыть её нельзя
- Клантаг этой программой не меняется: в играх он берётся из основной группы
  Steam, а не из произвольного текста

## Безопасность

`%APPDATA%\SteamNick\config.json` содержит **токен твоей сессии Steam** — по
сути ключ от аккаунта на время жизни cookie. Не выкладывай этот файл, не
показывай его на стримах и не прикладывай к issue. В репозиторий он попасть не
может: лежит вне папки проекта и вдобавок закрыт `.gitignore`.

Если токен всё же куда-то попал — выйди из аккаунта в браузере
(**Steam → Настройки → Безопасность → Выйти со всех устройств**), старая cookie
сразу перестанет действовать.

## Сборка exe

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name SteamNick --collect-all customtkinter steam_nick_gui.py
```

Готовый файл появится в `dist/`. Настройки он держит в `%APPDATA%\SteamNick`, а
не рядом с собой, поэтому exe можно переносить куда угодно и даже удалить —
пресеты и картинки останутся.
